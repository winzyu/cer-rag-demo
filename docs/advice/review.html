Advice Catalogue Review

Every candidate below is a proposal, not shipped copy. Code selects an entry by matching a detected event or instrument-health signal; the model only phrases what it is handed. Approving an entry means the wording is defensible as written, the tier is right, and Clean Earth Rovers is willing to stand behind it appearing verbatim in a customer-facing answer. Draft text is reproduced exactly as written by the drafting agents — nothing here has been tidied, shortened, or rephrased.

To print or save as PDF: Ctrl/Cmd+P. Controls and filters are hidden in print.

Trigger reachability — read before approving

Several entries are keyed to event types the pipeline cannot currently produce on live data. They are still worth approving — approval is cheap and each gap is a fixable code defect — but a first release should not depend on them.
